# 张凯文 × 刘明玥婚礼邀请

本仓库正在从原生微信小程序迁移为移动优先的婚礼 Web H5。

- Web 新版本：[`web/`](web/)
- 原微信小程序：保留在仓库根目录，便于迁移期间视觉与内容对照

Web 版本使用 Vue 3、TypeScript、Vite、Node.js、Fastify 与 MySQL，计划部署至 `wedding.nczkevin.com`。开发和部署说明见 [`web/README.md`](web/README.md)。

## 原微信小程序

原生微信小程序实现，视觉延续婚礼提案中的深海蓝幕布、黑色舞台、银白花艺与装置艺术语言。

## 页面

- 邀请：首页、倒计时、场地与 RSVP 入口
- 流程：婚礼时间线、当日活动、着装与宾客提示
- 互动：照片选择、语音/文字祝福
- 漫游：从婚礼酒店出发的景德镇景点推荐与地图导航
- RSVP：出席状态、人数、饮食备注和本地回执

## 本地预览

1. 打开微信开发者工具。
2. 选择“导入项目”，目录指向本仓库根目录。
3. 当前 `project.config.json` 使用 `touristappid`，可直接预览；真机测试和发布前替换为正式小程序 AppID。

## 上线前必须确认

主要婚礼资料集中在 [`config/wedding.js`](config/wedding.js)：

- 最终流程时间
- 酒店地址与地图定位（当前已确认，发布前建议在真机地图中复核入口）
- RSVP 截止日期（目前界面示例为 2026 年 8 月 20 日）
- 着装建议

还需补充：

- 背景音乐音频与播放授权说明
- 云开发环境 ID

## 数据说明

第一版在没有云环境的情况下也能完整演示：RSVP 与文字祝福写入微信本地存储，照片和录音保留在当前会话中。正式给宾客使用前，应接入微信云开发：

- RSVP 和祝福写入云数据库
- 照片、语音上传云存储
- 管理端导出宾客回复

这样可以保持现有页面与交互不变，只替换数据提交层。

## 视觉资源

`assets/images/` 中的婚礼场景视觉以婚礼提案为构图与风格参考，使用 imagegen 重新绘制；`1.jpg` 至 `4.jpg` 为新人提供的真实婚纱照，已用于 Web 邀请页的肖像章节与邀请前情绪过渡。景德镇漫游视觉位于 `packages/travel/images/`。所有图片均按竖屏浏览场景控制了尺寸和加载体积。
